## 1. Firebase ルールを本番版にする（花井、2 分）
Realtime Database → ルール → 以下に置き換えて公開。変更点は `rooms` だけ（読み取りはログイン済みのみ、書き込み禁止）。

```json
{
  "rules": {
    "users": {
      "$uid": {
        ".read": "auth != null && auth.uid == $uid",
        ".write": "auth != null && auth.uid == $uid"
      }
    },
    "groups": {
      "$code": {
        ".read": "auth != null && root.child('users/' + auth.uid + '/groups/' + $code).exists()",
        ".write": "auth != null && root.child('users/' + auth.uid + '/groups/' + $code).exists()",
        "meta": { ".read": "auth != null" }
      }
    },
    "rooms": {
      "$roomCode": { ".read": "auth != null", ".write": false }
    }
  }
}
```
- 効果: v1 を開いたままの人の保存は失敗するが、v1 は端末内では動き続ける（データは消えない）。v2 の移行フロー（ログイン後に読む）はそのまま動く
