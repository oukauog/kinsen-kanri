## 5. 花井の確認手順

本番 URL: https://kinsen-kanri.vercel.app/

1. **Vercel**: ダッシュボードの Deployments で、main（dfa5355「工事5の報告書と仕様書 §3 の並び順を追加」）のデプロイが **Ready** で、Production になっていること
2. **PC（Chrome など）** で本番 URL を開き、ログインする
   - 左の一覧が、五十音順ではなく参加した順（古いものが上）に変わっていること（想定どおり）
   - 各行の右端の「⋮⋮」をドラッグして並べ替えられること。「⋮⋮」をクリックしただけではグループが切り替わらないこと
   - 再読み込みしても並び順が残ること
   - 「テスト」で始まるグループの「清算」を開き、過去の清算でチェック済みの送金の横線が「A → B」だけに付いていること（「✓ 名前 日時」には付かない）
3. **iPhone の Safari** で本番 URL を開き、同じアカウントでログインする
   - ☰ のドロワーの一覧が、PC で並べ替えた順と同じであること
   - ドロワーの中で「⋮⋮」に指を置いて動かすと並べ替えられ、画面がスクロールに取られないこと
   - 「テスト」で始まるグループの「清算」で、チェック済みの送金の「✓ 名前 日時」が名前の下の行に出て、金額が右で切れないこと
4. **広島旅行のデータが変わっていないこと**: 広島旅行を開き、支払いの件数・合計・残高・過去の清算が、反映前と同じであること
   - 今回の変更で `groups/{code}` 側に書くものはありません
   - 並べ替えをすると、書くのは自分の `users/{uid}/groups` の order だけです
   - 広島旅行は見るだけにして、並べ替え以外の操作（チェックの付け外し・支払いの編集など）はしないでください
