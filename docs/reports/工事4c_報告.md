## 3. 追加した CSS 規則の全文

`css/v2.css` の末尾、既存の `@media (max-width: 640px) { … }` の**内側**に足しました。

```css
  /* 工事4c: iOS Safari の自動ズーム対策。
     入力欄の文字が 16px 未満だとフォーカス時に画面が拡大され、
     body が position: fixed のため戻せなくなる。スマホ幅では 16px にする。
     index.html の .form-input（0.9rem）に勝たせるため、
     要素名 + クラス（詳細度 0,1,1）で指定する（!important は使わない）。
     padding は変えないので、欄の高さがわずかに増えるだけ。 */
  input.form-input,
  select.form-input,
  textarea.form-input,
  input.member-row-input {
    font-size: 16px;
  }
```

### 詳細度で勝つ根拠

| セレクタ | 場所 | 詳細度 | font-size |
|---|---|---|---|
| `.form-input` | `index.html` の `<style>`（102 行目） | **0, 1, 0** | 0.9rem = 14.4px |
| `.member-row-input` | `css/v2.css`（158 行目） | **0, 1, 0** | 0.88rem = 14.08px |
| `input.form-input` / `select.form-input` / `textarea.form-input` / `input.member-row-input` | `css/v2.css` の `@media` 内（今回追加） | **0, 1, 1** | 16px |

- 「要素名（タイプセレクタ）1 つ + クラス 1 つ」で **0,1,1**。既存はどちらもクラス 1 つだけの **0,1,0** なので、**詳細度で上回ります**（読み込み順に依存しません）
- `@media` は詳細度を上げも下げもしないので、勝敗は上の比較だけで決まります
- `!important` は使っていません（スクリプト側でも、追加する宣言に `!important` が含まれていないことを機械的に確認しています）
- `.form-input` は `<input>` だけでなく `<select>`（支払った人）にも付くため、`input` / `select` / `textarea` の 3 つを並べました。実際に `#payPayer`（select）が 16px になることも確認済みです（§4）

### 影響範囲
- `@media (max-width: 640px)` の中だけなので、**PC 幅（641px 以上）は一切変わりません**（実測で確認。§4）
- `padding: 9px 12px` はそのままなので、欄の高さが文字 1.6px 分だけ増えます（依頼どおり許容）
- viewport の `<meta>` は変更していません。`maximum-scale` / `user-scalable=no` は**追加していない**ので、利用者のピンチ拡大は従来どおり使えます

## 7. 要判断・申し送り

1. **16px 未満の入力欄は、スマホ幅では残っていません**（§4 の全走査で確認）。今後 `index.html` や `ui.js` に新しい入力欄を足すときは、`class="form-input"` を付けておけば自動的に 16px になります。**付け忘れると同じ不具合が再発します**
2. **チェックボックス・ラジオ・ファイル選択**（`payPending`、送金チェック、取り込むグループの選択、`importFile`）は文字入力しないため対象外にしました。iOS はこれらのタップではズームしません
3. **欄の高さがわずかに増えます**（文字 14.4px → 16px、padding は据え置き）。支払いモーダルは縦に少し長くなります。詰めたい場合は、スマホ幅だけ `padding` を `8px 12px` などに減らす手がありますが、今回は依頼どおり触っていません
4. **根本の対処ではありません**。今回は「ズームさせない」ことで回避しています。`body { position: fixed; overflow: hidden }`（v1 からの作り）をやめれば、万一ズームしても戻せるようになりますが、レイアウト全体に影響する変更なので別工事として検討してください
5. **次の候補**（今回は触っていません）: ホーム画面アイコン（`manifest.json` / `apple-touch-icon`）、xlsx/CSV 取込の復元、2 端末同時の清算確定（工事3 §7-2）、スマホの見た目細部
