## 工事1 の範囲
### 1-A. 準備（最初に）
- `node -v` で Node.js を確認。無ければ `winget install OpenJS.NodeJS.LTS` を試み、入らなければ**ここで止めて**報告書に書く（テストと構文チェックに必須）
- `v2` ブランチ作成、`tools/`・`js/`・`css/`・`tests/`・`docs/reports/` を作成

### 1-B. ロジックの切り出しと固定テスト（C-1、実装より先に）
- v1 の `calcBalances` と `calcSettlement`、按分の計算を `js/calc.js` に純粋関数として切り出す（DOM・Firebase に依存しない。ブラウザからは `<script src>` で、Node からは `module.exports` で使えるように）
- `tests/calc.test.js` を Node 標準の `assert` だけで書き、`docs/30_テストケース_清算.md` のケース1（36 件、残高 4 人、送金 3 本と順序）とケース2（境界）を期待値にする。**v1 の挙動をそのまま期待値にする**（支払者が対象外のときの v1 の癖も含めて変えない）
- `node tests/calc.test.js` が全通過するまで先へ進まない

### 1-C. v2 本体（新規ファイル中心）
- `js/firebase-init.js`: Firebase compat（app / auth / database）を gstatic CDN から読み込む `<script>` は `index.html` 側、初期化と設定値はこのファイル。設定は次をそのまま使う（クライアント公開前提の値）:


- `js/auth.js`: Google ログイン（`signInWithPopup` → 失敗時 `signInWithRedirect`）、ログアウト、`onAuthStateChanged` で画面切替。未ログイン時はログイン画面のみ
- `js/store.js`: `users/{uid}/groups`、`groups/{code}/{meta,members,payments}` への読み書き。すべてレコード単位の `set` / `update` / `remove`。リスナー（`on('value')` 等）で変更を UI へ通知。配列は使わず ID キーのオブジェクト（`participants` は `{mid:true}`）。`settlementId: null`、`pending: false` は今から書いておく
- `js/ui.js`: 画面。左サイドバー＝参加グループ一覧（リアルタイム）、「＋ グループを作成」、「コードで参加」（`meta` を読んで名前を確認 → `users/{uid}/groups/{code}` に登録 → 参加）。グループ画面＝残高カード、支払い入力（v1 と同じ項目）、履歴、編集・削除、清算ボタン（送金リストの表示のみ）。グループ設定＝名前変更、メンバー追加・名前変更、共有コード表示（タップでコピー）、退出、削除（確認ダイアログ）。ヘッダ＝表示名・アイコン・ログアウト、接続状態の最小インジケータ（`.info/connected` で色）
- `css/v2.css`: 追加スタイル。v1 の見た目（配色、カード、モーダル、スマホ用サイドバー）は維持
- `index.html` の変更（Python スクリプト経由、最小限）: ① v1 のインライン `<script>…</script>` ブロックの撤去 ② Firebase compat と `js/*.js`、`css/v2.css` の読み込みタグ追加 ③ 必要な DOM の最小変更（ログイン画面、ヘッダ右の表示）。旧「☁ 設定」バッジは撤去。CSV/xlsx のボタンは非表示にする（コードは残してよい、工事4 で復元）
- 日本語文字列は数値実体参照にせず UTF-8 でそのまま書く
- **含まない**: CSV/xlsx 出力・取込、旧 rooms からの移行、清算レコード、金額確認中、誰が入力したか表示

### 1-D. 確認とコミット
- 編集のたびに `node --check js/*.js`（各ファイル）、`node tests/calc.test.js`
- ローカル確認は `python -m http.server 8000` で `http://localhost:8000` を開く（`localhost` は Firebase Auth の承認済みドメインに既定で入っている。`file://` では Google ログインが動かない）。ブラウザで: ログイン → テストグループ作成 → 支払い追加・編集・削除 → 別タブで同じアカウントで開き、片方の変更が他方に即反映されることを確認 → コードで参加 → 退出
- 動いた状態ごとにコミット（1 行目 50 字以内、日本語可）。最後に `git push -u origin v2`
